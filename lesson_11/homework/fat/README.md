# Домашнее задание: библиотека

`main.go` - сервис библиотеки целиком в одном обработчике: HTTP, правила и хранение. Разрежьте его на слои `entity`, `usecase`, `repository`, `delivery` так, чтобы `go test ./homework/fat/` оставался зелёным. `main_test.go` менять нельзя.

Правила: книгу нельзя выдать, если она уже выдана; у читателя не больше 3 книг; срок возврата 14 дней.

```
POST /loans {"book_id": 1, "reader_id": 2} → 201 {"due": "дата через 14 дней в формате YYYY-MM-DD"}
```

## Шаги

1. Создайте папки `entity`, `usecase`, `repository`, `delivery` внутри `homework/fat`.
2. Первая строка каждого файла - имя пакета, как у папки: `package usecase`.
3. Всё, что вызываете из другого пакета, пишите с большой буквы: `loan` → `entity.Loan`, `lend` → `delivery.Lend`. Ошибка `not exported` значит, что буква осталась маленькой.
4. Импорт пишется от имени модуля из `go.mod`: `import "clinic/homework/fat/usecase"`.
5. Переносите по одному куску и после каждого шага запускайте `go test ./homework/fat/`.
6. `newMux()` в `main.go` собирает слои: repository → usecase → delivery.

Тест зелёный и до разрезки: он проверяет поведение, а не слои. Слои проверьте так:

```sh
go list -f '{{.ImportPath}}: {{.Imports}}' ./homework/fat/...
```

В строке `usecase` не должно быть `net/http` и `sync`. Хранилище с данными в `delivery` нужно искать чтением кода: команда показывает только импорты. `map` для JSON-ответа допустима.

## Запуск

Из папки `code/`, где лежит `go.mod`:

```sh
go run ./homework/fat
```

Сервис займёт терминал. Откройте второй терминал в той же папке:

```sh
curl -i -X POST localhost:8080/loans -d '{"book_id": 1, "reader_id": 2}'
go test ./homework/fat/...
```

Первый запрос вернёт 201, повторный с той же книгой вернёт 409. Данные пропадут при перезапуске. Для остановки нажмите Ctrl+C в первом терминале. Не запускайте одновременно клинику: она тоже использует порт 8080.

Кроме разделения на слои нужен собственный тест usecase с подделкой repository на три случая. Полные условия и критерии, до 10 баллов, находятся в `../../../ДЗ.md`.

## Запуск сервиса и тестов после разрезки на слои

Все команды выполняются из корневой папки модуля (где лежит `go.mod`, например `code/` или `lesson_11/`):

### Запуск HTTP-сервера

```sh
go run ./homework/fat
```

Сервис запустится на `http://localhost:8080`. Для проверки во втором терминале выполните:

```sh
curl -i -X POST localhost:8080/loans -d '{"book_id": 1, "reader_id": 2}'
```

### Запуск тестов и проверок

```sh
# Юнит-тесты бизнес-логики (usecase с подделкой хранилища)
go test -v ./homework/fat/usecase/

# Все тесты библиотеки (включая интеграционный тест HTTP)
go test -v ./homework/fat/...

# Все тесты проекта и статический анализатор
go test ./...
go vet ./...

# Проверка зависимостей между слоями
go list -f '{{.ImportPath}}: {{.Imports}}' ./homework/fat/...
```
